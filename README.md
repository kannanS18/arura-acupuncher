# Arura Wellness Studio — Acupuncture & Counselling Centre

Official web application for **Arura Wellness Studio** (Virugambakkam, Chennai), led by **Dr. Nivedha Priyadharshini** (`MD (Acu)`, `Cambridge Intl Dip.`, `PG Dip. Counselling Therapy`).

## ✨ Features
- **Authentic Clinical Directives:** Full integration of classical 14-meridian acupuncture physics and Cambridge evidence-based psychotherapy.
- **Dedicated Distinct Pages:**
  - `Home`: Clinical overview, philosophy, authentic needle imagery, and transparent patient care.
  - `About Us`: Clinical background, aseptic standards, and treatment room acoustic specifications.
  - `Doctor`: Lead Physician profile with verified medical ID badge, credentials dossier (`DEG-01` to `DEG-03`), and clinical modalities.
  - `Clinic`: Complete transparent medical consultation & treatment tariff schedule.
  - `Blog`: 6 comprehensive doctor-authored clinical guides with dedicated reading pages (`/blog/:id`).
  - `Booking`: Interactive 3-step appointment scheduling with automated WhatsApp concierge integration.
- **Mobile-First Experience:** 
  - Ultra-clean top utility bar with tactile touch targets.
  - Elevated central booking bar with direct call, WhatsApp concierge, and turn-by-turn clinic GPS navigation.

## 🛠 Tech Stack
- **Framework:** React 18, Vite
- **Styling:** Tailwind CSS, Lucide React icons
- **Routing:** React Router v6
- **Typography:** Instrument Sans, Instrument Serif

## 🚀 Getting Started
```bash
# Install dependencies
npm install

# Start local development server
npm run dev

# Build for production
npm run build
```
